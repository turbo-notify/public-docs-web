O Turbo Notify reconhece grupos do WhatsApp como entidades de primeira
classe — mensagens recebidas em grupo trazem o contexto da conversa, e
o envio para grupos usa o identificador público `grp_{hex32}`.

## Conceitos

### Identificador público `grp_`

Toda referência pública a um grupo usa o formato `grp_` + 32 caracteres
hexadecimais, derivado de um identificador interno, no mesmo formato dos
demais prefixos públicos (`msg_`, `ct_`, `req_`, `evt_`).

> O identificador do WhatsApp (`120363xxxxx@g.us`) **nunca** é exposto
> em respostas, webhooks ou polling — apenas o `grp_{hex32}` do Turbo Notify.

### Campo `to` polimórfico

O campo `to` discrimina por presença de chave — sem campo `kind` ou `type`:

- **1:1** → `to: { "number": "+55..." }` — destinatário pessoa.
- **Grupo** → `to: { "group_id": "grp_..." }` — destinatário grupo.
- **Por contato** → `to: { "contact_id": "ct_..." }` — resolve o telefone a partir do registro de contato do Turbo Notify.

A mesma regra vale para os payloads de webhook e polling: quando
`to.group_id` está presente, o destinatário lógico é o grupo.
Mensagens 1:1 preservam o shape pré-existente byte-idêntico.

### Campo `from` sempre é pessoa

Grupos não falam — participantes falam dentro de grupos. Portanto:

- Inbound: `from` é o participante que enviou a mensagem no grupo.
- Outbound: `from` é o número Turbo Notify que enviou a mensagem.

Em nenhum cenário `from` carrega um `group_id`.

### Linha Turbo Notify (`number_alias` do envelope)

A linha Turbo Notify que participa da conversa — 1:1 ou grupo, inbound ou
outbound — é identificada pelo campo **`number_alias` do envelope** do evento
(`"main"` para o número principal ou o alias de um número extra). Resolva o
número/contato correspondente via `GET /v1/numbers/{alias}`.

```jsonc
// Inbound de grupo (envelope + data)
{
  "number_alias": "main",
  "data": {
    "from": { "contact_id": "ct_...", "name": "Cleverson", "number": "5571999258283" },
    "to":   { "group_id": "grp_e442553a56b14e2695f6acfd7d651b1a", "name": "TNT" }
  }
}

// Outbound para grupo (envelope + data)
{
  "number_alias": "main",
  "data": {
    "from": { "name": "Turbo Notify", "alias": "main", "number": "5511973117056" },
    "to":   { "group_id": "grp_e442553a56b14e2695f6acfd7d651b1a", "name": "TNT" }
  }
}
```

Para detectar mensagens de grupo, verifique a presença de `to.group_id`:

```js
const isGroup = "group_id" in data.to;
```

## Recebendo mensagens de grupo

Cada mensagem inbound proveniente de um grupo é entregue como
[`message.received`](/messages/webhook/#exemplo--messagereceived-grupo)
no webhook + polling. `from` é o participante que enviou; `to` traz o
`group_id` e o snapshot do nome do grupo; a linha Turbo Notify que participa
do grupo é identificada pelo `number_alias` do envelope.

## Enviando para grupo

Para enviar a um grupo a partir do número principal, use `POST /v1/messages`. Para números extras, use `POST /v1/numbers/{alias}/messages` onde `{alias}` é o alias do número extra. O campo `to` assume a forma `{ "group_id": "grp_..." }`.

:::note[Requer plano BUSINESS ou superior]
Enviar mensagem para um `group_id` exige a feature `groups:messages`,
disponível a partir do tier `BUSINESS`. Em `FREE`/`SOLO` o envio é
recusado com `402 feature_not_available` — receber mensagens de grupo e
consultar detalhes continuam funcionando normalmente. Veja
[Limitações de grupos](/groups/limitations/) e
[Quota e uso](/usage/quota/#envio-para-grupos-exige-plano-business-ou-superior).
:::

:::tip[Usando números extras?]
Para enviar de um número extra para o grupo, use `/v1/numbers/{alias}/messages` onde
`{alias}` é o alias do seu número extra. [Saiba mais](/numbers/add/).
:::

O Turbo Notify resolve o `grp_{hex32}` para o JID interno do WhatsApp e
roteia a mensagem para o grupo pelo número identificado em `{alias}`. Para 1:1, o campo `to` é um objeto `{ "number": "+5511999999999" }`.

## Consultando grupos

`GET /v1/numbers/{alias}/groups` lista os grupos observados por um número,
paginado por cursor. `GET /v1/numbers/{alias}/groups/{group_id}` retorna o
detalhe de um grupo específico. Ambos disponíveis em qualquer tier — não
exigem a feature `groups:messages`.

**Escopo obrigatório:** `groups:read`.

```http
GET /v1/numbers/{alias}/groups?limit=20&cursor=<opaque>
GET /v1/numbers/{alias}/groups/{group_id}
```

| Parâmetro (listagem) | Tipo | Descrição |
| --------------------- | ---- | --------- |
| `cursor` | string | Token opaco retornado em `cursor` pela página anterior |
| `limit` | int | 1–200 (padrão 50) |
| `name` | string | Filtro parcial pelo nome do grupo |
| `include_left` | bool | Inclui grupos dos quais o número já saiu (padrão `false`) |

Cada item — tanto na listagem (`data[]`) quanto no detalhe — tem este shape:

```json
{
  "id": "grp_9f6f0b37c98043e5835822eeae550e77",
  "number_alias": "main",
  "name": "Grupo A",
  "description": "Equipe de suporte",
  "participants_count": 12,
  "is_announce_only": false,
  "is_locked": false,
  "ephemeral_seconds": null,
  "is_active": true,
  "picture": { "kind": "unavailable", "reason": "peer_has_none" },
  "created_at": "2026-05-25T10:00:00Z",
  "updated_at": "2026-05-25T10:05:00Z"
}
```

A listagem envelopa os itens em `{ "data": [...], "cursor": "...", "has_more": true }`.
`is_active` é `false` quando o número já saiu do grupo (só aparece na
listagem com `include_left=true`). `picture` é a mesma união discriminada
usada pelo endpoint dedicado — veja [Foto do grupo](/groups/picture/).

`GET /v1/numbers/{alias}/groups/{group_id}` retorna `400 invalid_group_id`
quando o `group_id` não bate com `^grp_[0-9a-f]{32}$` — o formato é validado
antes da consulta. Um `group_id` **bem-formado** que não existe, ou que
pertence a outro número/organização, retorna `404 group_not_found`.

## Quota e rate-limit

Um envio para grupo conta como **1 destinatário** no rate-limit diário —
independente de quantos participantes o grupo tenha. A quota de
contatos (`contact.*`) **não** é afetada por envios para grupos: grupos
nunca materializam contatos.

## Ciclo de vida de grupo

O Turbo Notify emite 10 webhooks adicionais quando o estado do grupo
muda. Consulte [eventos de ciclo de vida de grupo](/groups/lifecycle-events/) para
o catálogo completo.
