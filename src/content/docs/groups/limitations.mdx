title: Limitações de grupos
description: O que o Turbo Notify oferece e o que NÃO oferece para grupos do WhatsApp, e qual plano é preciso para enviar.
---

O suporte a grupos do Turbo Notify cobre o que você precisa para enviar e ler
mensagens e para reagir a mudanças no grupo por webhooks. Tarefas de
administração do grupo (criar grupos, gerenciar membros, alterar configurações)
**não** são oferecidas.

## Não suportado

| Recurso | Estado | Por quê |
|---|---|---|
| Criar grupo pela API | ❌ | Tarefa de administração, fora do foco em envio e recebimento de mensagens |
| Adicionar ou remover participante pela API | ❌ | Idem |
| Promover ou rebaixar admin pela API | ❌ | Idem |
| Listar participantes de um grupo | ❌ | Privacidade; os webhooks `group.participants_*` informam quem foi alterado |
| Editar nome, descrição ou imagem do grupo | ❌ | Tarefa de administração |
| Gerar link de convite do grupo | ❌ | Tarefa de administração |
| Listas de transmissão | ❌ | Recurso diferente de grupo, não oferecido |
| Canais (newsletters) | ❌ | Idem |

## Suportado

| Recurso | Status |
|---|---|
| Receber mensagens de grupos | ✅ (webhook `message.received` com `to.group_id` e `to.name`) |
| Enviar mensagens para grupos | ✅ (`POST /v1/numbers/{alias}/messages` com `to.group_id`), **requer plano `BUSINESS` ou superior** (veja abaixo) |
| Enviar indicador de digitação para grupos | ✅ (`POST /v1/numbers/{alias}/typing-indicator` com `to.group_id`), **requer plano `BUSINESS` ou superior** (veja abaixo) |
| Editar e apagar mensagens em grupo | ✅ |
| Reagir a mensagens em grupo | ✅, requer plano que inclua reações (a reação exige plano em qualquer conversa, não só em grupo) |
| Listar grupos do número (`GET /v1/numbers/{alias}/groups`) | ✅ (paginado por cursor: `cursor`, `limit`, `name`, `include_left`) |
| Consultar o detalhe de um grupo (`GET /v1/numbers/{alias}/groups/{id}`) | ✅ |
| Receber aviso quando o número entra ou sai de um grupo | ✅ (`group.joined` / `group.left`) |
| Receber aviso quando o nome, a descrição ou a imagem do grupo muda | ✅ |
| Receber aviso quando membros são adicionados, removidos, promovidos ou rebaixados | ✅ |

## Envio de mensagens para grupo exige plano BUSINESS ou superior

Receber mensagens de grupo, listar e consultar grupos pela API
(`GET /v1/numbers/{alias}/groups`) e receber os 10 webhooks de ciclo de
vida funcionam em qualquer plano. Apenas o **envio** para um
`group_id` (mensagem ou indicador de digitação) exige o recurso
`groups:messages`, disponível a partir do plano `BUSINESS`. Em `FREE`/`SOLO`
o envio é recusado com `402 feature_not_available`. Veja
[Envio para grupo](/messages/send/#envio-para-grupo),
[Indicador de digitação em grupos](/other-features/typing-indicator/#indicador-de-digitação-em-grupos)
e [Cota e uso](/usage/quota/#envio-para-grupos-exige-plano-business-ou-superior).

## Identificador público

`grp_{hex32}` (32 caracteres hexadecimais). O identificador do WhatsApp
(`120363...@g.us`) **nunca** aparece na API ou nos webhooks: apenas o formato
do Turbo Notify.

## Cota e limite de velocidade

Uma mensagem para grupo conta como **1 destinatário** no limite diário de
destinatários, não importa o tamanho do grupo. Ela não conta na cota de contatos.

## Recuperação

Se você perder o nome de um grupo (por exemplo, se um webhook não foi
entregue), espere a próxima mensagem recebida no grupo: o webhook
`message.received` traz `to.name` (o nome do grupo).
Você também pode consultar
[`GET /v1/numbers/{alias}/groups/{id}`](/groups/overview/#consultando-grupos) a
qualquer momento.
