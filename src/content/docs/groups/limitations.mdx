---
title: Limitações de grupos
description: Recursos de grupos WhatsApp que o Turbo Notify NÃO suporta.
---

O Turbo Notify é uma plataforma de **mensageria transacional + observabilidade**.
Suporte a grupos cobre o que a API precisa para enviar e ler mensagens, e
para reagir a mudanças no grupo via webhooks. Operações administrativas
de grupo (criação, gerenciamento de membros, alteração de configurações)
**não** estão no escopo.

## Não suportado

| Recurso | Estado | Por quê |
|---|---|---|
| Criar grupo via API | ❌ | Operação administrativa; foge do escopo transacional |
| Adicionar/remover participante via API | ❌ | Idem |
| Promover/rebaixar admin via API | ❌ | Idem |
| Listar participantes de um grupo | ❌ | Privacidade; o webhook `group.participants_*` entrega quem foi alterado |
| Editar nome/descrição/imagem do grupo | ❌ | Operação administrativa |
| Gerar link de convite do grupo | ❌ | Operação administrativa |
| Listas de transmissão (broadcast) | ❌ | Mecanismo distinto de grupo; fora do escopo |
| Newsletters | ❌ | Idem |

## Suportado

| Recurso | Status |
|---|---|
| Receber mensagens de grupos | ✅ (webhook `message.received` com sibling `group`) |
| Enviar mensagens para grupos | ✅ (`POST /v1/numbers/{alias}/messages` com `to.group_id`) — **requer plano `BUSINESS` ou superior**, veja abaixo |
| Enviar indicador de digitação para grupos | ✅ (`POST /v1/numbers/{alias}/typing-indicator` com `to.group_id`) — **requer plano `BUSINESS` ou superior**, veja abaixo |
| Reagir, editar, deletar mensagens em grupo | ✅ |
| Listar grupos do número (`GET /v1/numbers/{alias}/groups`) | ✅ (paginado por cursor — `cursor`, `limit`, `name`, `include_left`) |
| Consultar detalhe de um grupo (`GET /v1/numbers/{alias}/groups/{id}`) | ✅ |
| Receber notificação quando entra/sai de grupo | ✅ (`group.joined` / `group.left`) |
| Receber notificação quando nome/descrição/imagem do grupo muda | ✅ |
| Receber notificação quando membros são adicionados/removidos/promovidos/rebaixados | ✅ |

## Envio de mensagens para grupo exige plano BUSINESS ou superior

Receber mensagens de grupo, listar grupos (via webhooks) e consultar
detalhes funcionam em qualquer tier. Apenas o **envio** outbound para um
`group_id` — mensagem ou indicador de digitação — exige a feature
`groups:messages`, disponível a partir do tier `BUSINESS` — em `FREE`/`SOLO`
o envio é recusado com `402 feature_not_available`. Veja
[Envio para grupo](/messages/send/#envio-para-grupo),
[Aviso em grupos](/other-features/typing-indicator/#aviso-em-grupos)
e [Quota e uso](/usage/quota/#envio-para-grupos-exige-plano-business-ou-superior).

## Identificador público

`grp_{hex32}` (32 hex chars do UUID interno). O identificador bruto do
WhatsApp (`120363...@g.us`) **nunca** é exposto via API ou webhook —
apenas o formato TN.

## Quota e rate-limit

Mensagem para grupo = **1 destinatário** no rate-limit diário,
independente do tamanho do grupo. Não conta na quota de contatos.

## Recuperação

Se você perder o nome de um grupo (ex: webhook caiu antes de
ser entregue), aguarde a próxima mensagem inbound — o webhook
`message.received` carrega o `group.name` resolvido. Alternativamente,
consulte `GET /v1/numbers/{alias}/groups/{id}` a qualquer momento.
