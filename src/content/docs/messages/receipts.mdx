Após uma mensagem ser enviada, o WhatsApp retorna confirmações de entrega e leitura. O histórico de recibos registra essas confirmações — `delivered` (entregue no dispositivo) e `read` (lida pelo destinatário) — em ordem cronológica crescente.

## Consultar recibos

Para listar o histórico de recibos de uma mensagem, faça uma requisição `GET` informando o `message_id` retornado no envio.

**Endpoint:** `GET /v1/messages/{message_id}/receipts`

**Autenticação:** Bearer token com escopo `messages:read`

**Parâmetros de caminho:**

| Parâmetro    | Tipo   | Descrição                               |
| ------------ | ------ | --------------------------------------- |
| `message_id` | string | Identificador público da mensagem (`msg_{hex32}`) |

## Estrutura da resposta

| Campo                    | Tipo    | Descrição                                                          |
| ------------------------ | ------- | ------------------------------------------------------------------ |
| `message_id`             | string  | Identificador público da mensagem.                                 |
| `receipts`               | array   | Lista de transições de status, em ordem cronológica crescente.     |
| `receipts[].from`            | object  | Parte que emitiu o recibo. Omitido em recibos legados (pré-2026-06) e quando nenhuma informação de identidade está disponível (e.g. recibos de dispositivo vinculado). |
| `receipts[].from.contact_id` | string  | Identificador público do contato (`ct_{hex32}`). Omitido quando não disponível. |
| `receipts[].from.name`       | string  | Nome de exibição do WhatsApp (PII — propriedade do tenant). Omitido quando não disponível. |
| `receipts[].from.number`     | string  | Número E.164 sem `+` de quem confirmou o recibo. Omitido para recibos de dispositivo vinculado (LID) onde o número do confirmador não está disponível. |
| `receipts[].status`      | string  | Status atingido nesta transição (`delivered` ou `read`).           |
| `receipts[].at`          | string  | Timestamp ISO 8601 de quando o status foi registrado.              |

## Tabela de status

| Status      | Descrição                                                                   |
| ----------- | --------------------------------------------------------------------------- |
| `delivered` | Confirmação do WhatsApp de que a mensagem foi entregue ao dispositivo.      |
| `read`      | Confirmação do WhatsApp de que a mensagem foi lida pelo destinatário.       |

> **Nota:** Apenas confirmações enviadas pelo WhatsApp (`delivered` e `read`) são registradas nos recibos. O status `sent` (envio ao WhatsApp) pode ser consultado via [`GET /v1/messages/{id}/status`](/messages/status/).

## Erros possíveis

| Status | Código de erro   | Descrição                                            |
| :----: | ---------------- | ---------------------------------------------------- |
| `403`  | `not_authorized`    | A chave de acesso está inválida ou ausente.                       |
| `403`  | `insufficient_scope` | A chave de acesso não possui o escopo `messages:read`.           |
| `404`  | `not_found`         | A mensagem não foi encontrada.                                    |
| `500`  | `internal_error`    | Erro interno inesperado no servidor.                              |
