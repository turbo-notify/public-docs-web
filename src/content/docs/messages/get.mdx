Recupere o conteúdo completo, o status de entrega e a referência de mídia de qualquer mensagem enviada ou recebida na sua conta, usando o `message_id` como identificador.

**Escopo obrigatório:** `messages:read`

## Campos da resposta

`from` e `to` são objetos com forma direção-aware — o mesmo shape usado nos webhooks:

- **Outbound:** `from = { number, alias, name? }`, `to = { number, name? }`.
- **Inbound:** `from = { number, name? }`, `to = { number, alias, name? }`.

Os campos `name` são opcionais: em outbound, `from.name` carrega o nome de exibição do número TN (capturado na conexão) e `to.name` traz o nome de contato em cache (warmed via mensagens inbound); em inbound, `from.name` é o `push_name` do contato e `to.name` é o nome do número TN que recebeu.

| Campo | Tipo | Descrição |
| ----- | ---- | --------- |
| `message_id` | string | Identificador público da mensagem (`msg_` + 32 hex) |
| `direction` | string | `outbound` (enviada) ou `inbound` (recebida) |
| `from` | object | Remetente — shape direção-aware (ver acima) |
| `to` | object | Destinatário — shape direção-aware (ver acima) |
| `content_type` | string | `text`, `image`, `audio`, `video`, `document`, `sticker`, `location`, `contact` ou `calendar` |
| `status` | object | `{state, at}` — estado atual de entrega |
| `preview` | string | Permanente — recorte grapheme-aware de até 500 caracteres do conteúdo |
| `body` | object\|null | Conteúdo estruturado completo; `null` quando expirado pela política de retenção |
| `body_expired` | boolean | `true` quando o corpo foi removido pelo ciclo de retenção |
| `media` | object\|null | Bloco de mídia; `null` para tipos não-mídia |
| `sent_at` | string\|null | Timestamp ISO 8601 UTC em que o WhatsApp confirmou o envio da mensagem outbound (apenas outbound; sempre `null` para inbound ou se ainda não confirmado). |
| `delivered_at` | string\|null | Timestamp ISO 8601 UTC em que o dispositivo do destinatário confirmou a entrega (apenas outbound; sempre `null` para inbound). |
| `read_at` | string\|null | Timestamp ISO 8601 UTC em que o destinatário confirmou a leitura (apenas outbound; sempre `null` para inbound). |
| `created_at` | string | Timestamp ISO 8601 de criação |
| `updated_at` | string | Timestamp ISO 8601 da última atualização de status |
| `origin` | string\|null | `"api"` (envio via REST) ou `"channel"` (digitada no celular) para mensagens outbound; `null` para inbound |
| `quoted_message_id` | string\|null | `msg_{hex32}` da mensagem citada quando esta é uma resposta; `null` caso contrário. Persistido como coluna dedicada — sobrevive ao expurgo de `body`. |

### Bloco de mídia

Presente quando `content_type` é `image`, `audio`, `video`, `document` ou `sticker`. O campo `media` é uma **união discriminada** pelo campo `kind`:

#### `kind: "available"`

Mídia disponível para download. Requer <DashboardLink path="/settings/integrations/storage">Object Storage configurado</DashboardLink>.

| Campo | Tipo | Descrição |
| ----- | ---- | --------- |
| `kind` | string | `"available"` |
| `storage` | string | `"tenant_storage"` (URL pré-assinada do seu bucket) |
| `url` | string | URL pré-assinada de download |
| `url_expires_at` | string\|null | Timestamp de expiração da URL pré-assinada |
| `mime_type` | string\|null | Tipo MIME do arquivo (ex: `image/jpeg`, `application/pdf`) |
| `size_bytes` | integer\|null | Tamanho do arquivo em bytes |
| `hash` | string\|null | Hash SHA-256 do arquivo (ex: `sha256:a1b2c3...`) |
| `caption` | string\|null | Legenda da mídia, quando presente |

#### `kind: "pending"`

Upload da mídia para o seu bucket ainda está em andamento. Aguarde alguns segundos e consulte novamente.

| Campo | Tipo | Descrição |
| ----- | ---- | --------- |
| `kind` | string | `"pending"` |
| `mime_type` | string\|null | Tipo MIME detectado |
| `size_bytes` | integer\|null | Tamanho do arquivo em bytes |
| `hash` | string\|null | Hash SHA-256 |
| `caption` | string\|null | Legenda da mídia |

#### `kind: "unavailable"`

Mídia não está disponível. O campo `reason` indica a causa.

| Campo | Tipo | Descrição |
| ----- | ---- | --------- |
| `kind` | string | `"unavailable"` |
| `reason` | string | `no_storage` — nenhum Object Storage configurado (envia `setup_hint`); `storage_circuit_open` — circuit breaker do storage aberto no recebimento (envia `setup_hint`); `upload_failed` — storage saudável, mas este item não pôde ser persistido (sem hint). O motivo é gravado no recebimento e lido literalmente; esta mensagem não é recuperada retroativamente — mensagens futuras voltam a ser armazenadas quando o circuito fecha. |
| `mime_type` | string\|null | Tipo MIME detectado |
| `size_bytes` | integer\|null | Tamanho do arquivo em bytes |
| `hash` | string\|null | Hash SHA-256 |
| `caption` | string\|null | Legenda da mídia |

### Sobre `body_expired`

O campo `body` contém o conteúdo estruturado completo da mensagem. Após o período de retenção (padrão: 30 dias), o corpo é removido e `body_expired` passa a ser `true`. O campo `preview` — primeiros 50 caracteres — é permanente e sempre estará presente.

### Sobre `media.kind`

Para receber mídia inbound com `kind: "available"`, configure a <DashboardLink path="/settings/integrations/storage">integração de Object Storage</DashboardLink> no Dashboard. Sem essa configuração, o Turbo Notify não tem onde armazenar a mídia e retorna `kind: "unavailable"` com `reason: "no_storage"`.

Quando o Object Storage está configurado, o Turbo Notify copia automaticamente cada mídia recebida para o seu bucket e retorna uma URL pré-assinada com validade configurável. A URL pré-assinada expira conforme o `url_expires_at` — você pode gerar uma nova consultando a mensagem novamente.

## Erros possíveis

| Status | Código de erro | Descrição |
| :----: | -------------- | --------- |
| `400` | `invalid_message_id` | O identificador não corresponde ao formato `msg_` + 32 hex. |
| `403` | `not_authorized` | A chave de acesso está inválida, ausente ou sem o escopo `messages:read`. |
| `404` | `not_found` | Mensagem não encontrada ou pertence a outro tenant. |
| `429` | `rate_limit_exceeded` | Limite de requisições ultrapassado. |
| `500` | `internal_error` | Erro interno inesperado no servidor. |
