---
title: Rotas flat para o número principal
description: As rotas /v1/messages, /v1/contacts e /v1/groups agora apontam diretamente para o número principal, sem precisar especificar o alias.
sidebar:
  order: 7
---

A partir desta versão, todas as operações do número principal podem ser realizadas
diretamente sem especificar o alias na URL:

| Nova rota flat | Equivalente |
|---|---|
| `POST /v1/messages` | `POST /v1/numbers/main/messages` |
| `GET  /v1/messages` | `GET  /v1/numbers/main/messages` |
| `GET  /v1/messages/{id}` | `GET  /v1/numbers/main/messages/{id}` |
| `GET  /v1/contacts` | `GET  /v1/numbers/main/contacts` |
| `GET  /v1/contacts/quota` | `GET  /v1/numbers/main/contacts/quota` |
| `GET  /v1/groups` | `GET  /v1/numbers/main/groups` |
| `POST /v1/typing-indicator` | `POST /v1/numbers/main/typing-indicator` |
| *(e todas as sub-rotas)* | |

A forma `/v1/numbers/main/…` continua funcionando normalmente e produz respostas
idênticas. Para **números extras**, continue usando `/v1/numbers/{alias}/…`.

Esta mudança não requer nenhuma alteração em integrações existentes.
