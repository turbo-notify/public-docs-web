Liste os contatos do tenant autenticado. Suporta filtros, paginação por cursor e ordenação.

## Endpoint

```http
GET /v1/contacts?limit=20&cursor=<opaque>
```

**Scope necessário:** `contacts:read`.

## Parâmetros de query

| Parâmetro | Tipo | Descrição |
| --------- | ---- | --------- |
| `limit` | int | Máx 100 (default 20) |
| `cursor` | string | Token opaco retornado em `next_cursor` |
| `phone` | string | Filtro exato por E.164 (`+5571999...`) |
| `push_name` | string | Match parcial (trigram) sobre `push_name` |
| `is_business` | bool | Filtra contatos com `business_profile` definido |
| `source` | enum | `inbound \| outbound \| self` |
| `has_messaged_in_window` | bool | Só contatos com `first_messaged_at` na janela atual |
