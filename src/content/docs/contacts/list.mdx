Liste os contatos da organização autenticada. Suporta filtros, paginação por cursor e ordenação.

Os contatos são escopados por número: `{alias}` é `main` (número principal) ou o alias de um número extra, e o mesmo telefone alcançado por dois números diferentes corresponde a dois contatos distintos.

## Endpoint

```http
GET /v1/contacts?limit=20&cursor=<opaque>
```

Para números extras: `GET /v1/numbers/{alias}/contacts?limit=20&cursor=<opaque>`

:::tip[Usando números extras?]
Para listar contatos de um número extra, use `/v1/numbers/{alias}/contacts` onde
`{alias}` é o alias do seu número extra. [Saiba mais](/numbers/add/).
:::

**Escopo obrigatório:** `contacts:read`.

## Parâmetros de consulta

| Parâmetro | Tipo | Descrição |
| --------- | ---- | --------- |
| `limit` | int | 1–200 (default 50) |
| `cursor` | string | Token opaco retornado em `cursor` |
| `phone` | string | Filtro exato por E.164 (`+5571999...`) |
| `name` | string | Correspondência parcial sobre o nome do contato |
| `source` | enum | `inbound \| outbound \| self \| mention` — `mention` é o contato observado pela primeira vez por ter sido **mencionado** em uma mensagem; contatos criados por menção **não** consomem quota de contatos |
| `contacted_in_cycle` | bool | Considera apenas contatos contactados via Turbo Notify dentro do ciclo de faturamento avaliado (novos ou recorrentes) |

Cada item é o mesmo objeto retornado por [Detalhe](/contacts/detail/). O
`phone_number` é o **E.164 completo** (sem máscara). A entidade de contato
mantém seus timestamps de ciclo de vida distintos
(`created_at`/`updated_at`/`first_messaged_at`/…) — não é o eco de um evento.
