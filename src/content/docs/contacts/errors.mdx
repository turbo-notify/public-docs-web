## Tabela de erros

| HTTP | `error` | Quando |
| ---- | ------- | ------ |
| 400  | `invalid_phone_number` | Filtro `phone` não está em E.164 |
| 400  | `invalid_contact_id` | `contact_id` não bate com `^ct_[0-9a-f]{32}$` |
| 400  | `invalid_cursor` | Cursor opaco corrompido |
| 402  | `contact_quota_exceeded` | Quota mensal de contatos distintos atingida |
| 404  | `contact_not_found` | ID inválido ou de outro organization |
| 404  | `contact_picture_unavailable` | Sem foto disponível para este contato |
| 429  | `rate_limit_exceeded` | Limite de refresh por minuto |

## Exemplo de resposta 402

Retornado pelo `SendMessageUseCase` quando o organization tenta mandar a primeira mensagem para um novo contato e a quota de contatos distintos está esgotada.

<ApiResponse status={402}>
```json
{
  "error": "contact_quota_exceeded",
  "details": {
    "quota": 100,
    "used": 100,
    "resets_at": "2026-06-14T00:00:00Z",
    "tier": "free"
  }
}
```
</ApiResponse>

**Ação recomendada:** upgrade plan. Diferentemente de 429, 402 não tem `Retry-After` — o erro é estrutural (a janela de 30 dias precisa rolar ou o tier precisa subir).

## Diferença 402 vs 429

| | 402 Payment Required | 429 Too Many Requests |
| - | -------------------- | --------------------- |
| Semântica | Estrutural — "upgrade plan" | Temporal — "retry depois" |
| Header | — | `Retry-After: <segundos>` |
| Reset | Em até 30 dias (janela rolling) ou upgrade | Em segundos/minutos |
| Quando | Quota mensal | Burst protection |

Veja também: [Quota e uso](/usage/quota/).
