Retorna o payload completo de um contato, incluindo todos os telefones associados, perfil de negócio (quando aplicável) e metadados da foto de perfil.

## Endpoint

```http
GET /v1/contacts/{contact_id}
```

**Scope:** `contacts:read`.

## Path

| Parâmetro | Tipo | Formato |
| --------- | ---- | ------- |
| `contact_id` | string | `ct_{hex32}` — regex `^ct_[0-9a-f]{32}$` |
