Retorna o payload completo de um contato, incluindo telefone, perfil de negócio (quando aplicável) e metadados da foto de perfil.

## Endpoint

```http
GET /v1/contacts/{contact_id}
```

**Scope:** `contacts:read`.

## Path

| Parâmetro | Tipo | Formato |
| --------- | ---- | ------- |
| `contact_id` | string | `ct_{hex32}` — regex `^ct_[0-9a-f]{32}$` |

## Resposta (200)

<ApiResponse status={200}>
```json
{
  "id": "ct_a1b2c3d4e5f6789012345678901234ab",
  "phone_number": "+5571999294756",
  "name": "João Silva",
  "status_about": "Disponível",
  "is_business": false,
  "business_profile": null,
  "is_self": false,
  "first_messaged_at": "2026-05-10T13:25:00Z",
  "last_seen_at": "2026-05-10T13:40:00Z",
  "last_interaction_at": "2026-05-10T13:42:00Z",
  "verified_on_whatsapp_at": "2026-05-10T13:25:00Z",
  "picture": {
    "kind": "available",
    "url": "https://cdn.example.com/contacts/ct_a1b2.jpg",
    "url_expires_at": "2026-05-10T14:25:00Z",
    "hash": "sha256:...",
    "fetched_at": "2026-05-10T13:25:00Z"
  },
  "created_at": "2026-05-10T13:25:00Z",
  "updated_at": "2026-05-10T13:42:00Z"
}
```

O `phone_number` é o **E.164 completo** (sem máscara) — o mesmo número já
exposto em `message.from`/`message.to` (ADR 2026-06-02). O campo `name` é o
push name do contato no WhatsApp (coerente com o triplo `{id, name, number}`
dos eventos `contact.*`). `picture` é uma união discriminada por `kind`
(`available` | `pending` | `unavailable`), espelhando o bloco de mídia dos
eventos; quando `kind` é `available`, o próprio bloco carrega `fetched_at`.
</ApiResponse>

## Erros

- `404 contact_not_found` — ID inválido ou pertencente a outro tenant.

Veja a [referência de erros](/contacts/errors/).
