O aviso de digitação permite que sua aplicação sinalize ao destinatário que uma mensagem está sendo preparada, simulando uma experiência de conversa mais natural.

## Aviso automático

O Turbo Notify gerencia automaticamente o aviso de digitação antes do envio de mensagens. Quando uma mensagem é enviada, o indicador de digitação é ativado por um breve período antes da entrega, proporcionando uma experiência mais humana sem necessidade de configuração adicional.

Use os endpoints abaixo apenas quando precisar de controle manual sobre o indicador de digitação.

## Início da digitação

Para sinalizar que uma mensagem está sendo preparada, envie uma requisição com `is_typing` igual a `true`.

## Destinatários disponíveis

O campo `to` aceita exatamente uma das três formas abaixo, igualmente à rota de [envio de mensagens](/messages/send/):

| Forma | Exemplo | Quando usar |
| ----- | ------- | ----------- |
| `number` | `{"number": "+5511999999999"}` | Número E.164 conhecido |
| `group_id` | `{"group_id": "grp_…"}` | Grupo do WhatsApp |
| `contact_id` | `{"contact_id": "ct_…"}` | ID do TN Contact (telefone resolvido internamente) |

## Aviso em grupos

Para enviar o indicador de digitação em um grupo do WhatsApp, use `to.group_id` com o identificador do grupo no lugar de `to.number`.

:::note[Requer plano BUSINESS ou superior]
Enviar indicador de digitação (assim como mensagem) para um `group_id` exige a
feature `groups:messages`, disponível a partir do tier `BUSINESS`. Em
`FREE`/`SOLO` você ainda **recebe** mensagens de grupo, lista grupos
localmente pelos webhooks e consulta detalhes — apenas o **envio** outbound
para grupo (incluindo o indicador de digitação) é bloqueado com `402`:

<ApiResponse
  status={402}
  body={{
    error: 'feature_not_available',
  }}
/>

Veja [Quota e uso](/usage/quota/#envio-para-grupos-exige-plano-business-ou-superior)
e [Limitações de grupos](/groups/limitations/).
:::

```bash title="typing-group.sh"
curl -X POST \
  https://api.turbonotify.com/v1/numbers/{alias}/typing-indicator \
  -H "Authorization: Bearer SUA_CHAVE" \
  -H "Content-Type: application/json" \
  -d '{
    "to": {"group_id": "grp_a1b2c3d4e5f6a1b2c3d4e5f6a1b2c3d4"},
    "is_typing": true
  }'
```

O `group_id` é o identificador do grupo no formato `grp_{hex32}`, retornado pelo endpoint de [listagem de grupos](/groups/overview/).

## Aviso por contact_id

Use `to.contact_id` para indicar digitação a um contato do catálogo TN sem informar o telefone diretamente. O telefone é resolvido internamente a partir do registro do contato.

```bash title="typing-contact.sh"
curl -X POST \
  https://api.turbonotify.com/v1/numbers/{alias}/typing-indicator \
  -H "Authorization: Bearer SUA_CHAVE" \
  -H "Content-Type: application/json" \
  -d '{
    "to": {"contact_id": "ct_a1b2c3d4e5f6a1b2c3d4e5f6a1b2c3d4"},
    "is_typing": true
  }'
```

## Aviso com número extra

O remetente do aviso de digitação é **sempre o alias do path**. Para digitar a partir de um
[número extra](/numbers/add/) cadastrado e ativo, use a forma aninhada com o alias desse número
no lugar de `{alias}`:

```bash title="typing.sh"
curl -X POST \
  https://api.turbonotify.com/v1/numbers/vendas-sp/typing-indicator \
  -H "Authorization: Bearer SUA_CHAVE" \
  -H "Content-Type: application/json" \
  -d '{
    "to": {"number": "+5511999999999"},
    "is_typing": true
  }'
```

A forma plana `POST /v1/typing-indicator` é um atalho que envia **sempre** a partir do número
principal (`main`). Um campo `from` no corpo é aceito por compatibilidade, porém **ignorado** em
ambas as formas — o path sempre vence.

Caso o alias informado no path não estiver cadastrado ou o número não estiver ativo, a operação
será rejeitada.

Saiba mais sobre os números extra em [Números Extras](/numbers/add/).

## Eventos de webhook

Operações de aviso de digitação são **fire-and-forget**: o `202 Accepted` confirma apenas o
aceite assíncrono e **nenhum evento de webhook** é entregue para essas operações.

## Erros possíveis

| Status | Código de erro          | Descrição                                          |
| :----: | ----------------------- | -------------------------------------------------- |
| `400`  | `invalid_json`          | O JSON da requisição está malformado ou inválido.  |
| `400`  | `contact_not_found`     | O `contact_id` informado em `to` não pertence ao organization.  |
| `400`  | `contacts_not_enabled`  | Envio por `contact_id` não está configurado nesta instância. |
| `400`  | `groups_not_enabled`    | Suporte a grupos não está habilitado nesta instância. |
| `402`  | `feature_not_available` | O recurso não está disponível no plano contratado. |
| `403`  | `not_authorized`        | A chave de acesso está inválida ou ausente.        |
| `403`  | `insufficient_scope`    | A chave de acesso não possui o escopo `messages:send` (resposta inclui `required_scope`). |
| `404`  | `group_not_found`       | O `group_id` informado em `to` não foi encontrado. |
| `422`  | `no_active_session`     | A organização não tem sessão WhatsApp conectada.   |
| `422`  | `sender_disconnected`   | O número extra do alias na URL está desconectado.  |
| `422`  | `sender_not_found`      | O alias/número informado não corresponde a nenhum remetente da conta. |
| `422`  | `session_not_connected` | A sessão do remetente não está conectada no momento do envio. |
| `500`  | `internal_error`        | Erro interno inesperado no servidor.               |
| `503`  | `whatsapp_unavailable`  | O WhatsApp está temporariamente fora do ar.        |
