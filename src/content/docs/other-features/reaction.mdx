O recurso de reação permite que sua aplicação envie ou remova reações em mensagens específicas, tornando as interações mais expressivas.

O endpoint é roteado pelo `message_id` da mensagem-alvo na URL — não há campo `to` no corpo, pois o destinatário é inferido da mensagem original.

## Adicionar uma reação

`POST /v1/messages/{message_id}/react` — adiciona uma reação à mensagem identificada por `{message_id}` (formato `msg_{hex32}`). Esta rota opera sobre o número principal. Para enviar a reação a partir de um número extra, use a forma completa `POST /v1/numbers/{alias}/messages/{message_id}/react` com o alias do número no path.

## Reação com número extra

Para enviar a reação a partir de um [número extra](/numbers/add/) cadastrado e ativo, basta usar o alias desse número diretamente no path da URL. O destinatário continua sendo inferido a partir do `message_id`.

```bash title="reaction.sh"
curl -X POST \
  https://api.turbonotify.com/v1/numbers/vendas-sp/messages/msg_abc123/react \
  -H "Authorization: Bearer SUA_CHAVE" \
  -H "Content-Type: application/json" \
  -d '{
    "reaction": "🎉"
  }'
```

Caso o alias informado na URL não estiver cadastrado como número extra ou não estiver ativo, a operação será rejeitada.

Saiba mais sobre os números extra em [Números Extras](/numbers/add/).

## Erros possíveis

| Status | Código de erro          | Descrição                                          |
| :----: | ----------------------- | -------------------------------------------------- |
| `400`  | `invalid_json`          | O JSON da requisição está malformado ou inválido.  |
| `400`  | `invalid_message_id`    | O `message_id` na URL não está no formato `msg_{hex32}`. |
| `402`  | `feature_not_available` | O recurso não está disponível no plano contratado. |
| `403`  | `not_authorized`        | A chave de acesso está inválida ou ausente.        |
| `403`  | `insufficient_scope`    | A chave de acesso não possui o escopo `messages:send` (resposta inclui `required_scope`). |
| `404`  | `message_not_found`     | O `message_id` não foi encontrado.                 |
| `422`  | `no_active_session`     | A organização não tem sessão WhatsApp conectada.   |
| `422`  | `sender_disconnected`   | O número extra do alias na URL está desconectado.  |
| `422`  | `sender_not_found`      | O alias/número informado não corresponde a nenhum remetente da conta. |
| `422`  | `session_not_connected` | A sessão do remetente não está conectada no momento do envio. |
| `500`  | `internal_error`        | Erro interno inesperado no servidor.               |
| `503`  | `whatsapp_unavailable`  | O WhatsApp está temporariamente fora do ar.        |

Para entender mais sobre o erro `message_not_found`, consulte a documentação sobre [Retenção](/messages/retention/).
