Controle quais números extras estão ativos para envio de mensagens. Números desativados permanecem cadastrados na conta, mas não podem ser usados como remetente.

## Cobrança

Números extras desativados continuam sendo cobrados enquanto estiverem cadastrados. Para encerrar a cobrança, é necessário remover o número. Consulte os detalhes em [Cobrança de Números Extras](/numbers/billing/).

## Pelo dashboard

Acesse a página de <DashboardLink path="/numbers">Números Extras</DashboardLink> no dashboard para ativar ou desativar números com um clique.

## Ativação

Para ativar (conectar) um número extra que está inativo, faça uma requisição POST para o endpoint de conexão informando o alias do número na URL.

<Tabs>
  <TabItem label="cURL">
    ```bash title="turbo-notify.sh"
    curl -X POST \
      https://api.turbonotify.com/v1/numbers/ALIAS_DO_NUMERO/connect \
      -H "Authorization: Bearer SUA_CHAVE"
    ```
  </TabItem>
  <TabItem label="Node">
    ```js title="turbo-notify.js"
    const response = await fetch('https://api.turbonotify.com/v1/numbers/ALIAS_DO_NUMERO/connect', {
      method: 'POST',
      headers: {
        'Authorization': 'Bearer SUA_CHAVE'
      }
    });

    const result = await response.json();
    console.log(result);
    ```
  </TabItem>
  <TabItem label="Python">
    ```python title="turbo_notify.py"

    url = "https://api.turbonotify.com/v1/numbers/ALIAS_DO_NUMERO/connect"
    headers = {
        "Authorization": "Bearer SUA_CHAVE"

    response = requests.post(url, headers=headers)
    result = response.json()
    print(result)
    ```
  </TabItem>
  <TabItem label="Go">
    ```go title="turbo_notify.go"
    package main

    import (
        "fmt"
        "io"
        "net/http"
    )

        req, _ := http.NewRequest("POST", "https://api.turbonotify.com/v1/numbers/ALIAS_DO_NUMERO/connect", nil)
        req.Header.Set("Authorization", "Bearer SUA_CHAVE")
        resp, _ := http.DefaultClient.Do(req)
        defer resp.Body.Close()
    ```

  </TabItem>
  <TabItem label="PHP">

  <TabItem label="C#">
    ```csharp title="TurboNotify.cs"

    client.DefaultRequestHeaders.Add("Authorization", "Bearer SUA_CHAVE");

        "https://api.turbonotify.com/v1/numbers/ALIAS_DO_NUMERO/connect",

    );

    Console.WriteLine(result);
    ```

  </TabItem>
  <TabItem label="Java">
    ```java title="TurboNotify.java"
    import java.net.http.*;
    import java.net.URI;

    public class TurboNotify {
        public static void main(String[] args) throws Exception {
            var client = HttpClient.newHttpClient();

            var request = HttpRequest.newBuilder()
                .uri(URI.create("https://api.turbonotify.com/v1/numbers/ALIAS_DO_NUMERO/connect"))
                .header("Authorization", "Bearer SUA_CHAVE")
                .POST(HttpRequest.BodyPublishers.noBody())
                .build();

            var response = client.send(request,
                HttpResponse.BodyHandlers.ofString());
            System.out.println(response.body());
        }
    }
    ```

## Erros possíveis

| Status | Código de erro     | Descrição                                                     |
| :----: | ------------------ | ------------------------------------------------------------- |
| `400`  | `invalid_json`     | O JSON da requisição está malformado ou inválido.             |
| `403`  | `not_authorized`   | A chave de acesso está inválida ou ausente.                   |
| `409`  | `invalid_status`   | O número já está no status solicitado.                        |
| `422`  | `number_not_found` | O alias informado não corresponde a nenhum número cadastrado. |
| `500`  | `internal_error`   | Erro interno inesperado no servidor.                          |
