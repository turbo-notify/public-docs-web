Controle quais números extras estão ativos para envio de mensagens. Números desativados permanecem cadastrados na conta, mas não podem ser usados como remetente.

## Cobrança

Números extras desativados continuam sendo cobrados enquanto estiverem cadastrados. Para encerrar a cobrança, é necessário remover o número. Consulte os detalhes em [Cobrança de números extras](/numbers/billing/).

## Pelo dashboard

Acesse a página de <DashboardLink path="/numbers">Números</DashboardLink> no dashboard para ativar ou desativar números com um clique.

## Ativação

Para ativar (conectar) um número extra que está inativo, faça uma requisição POST para o endpoint de conexão informando o alias do número na URL.

    ```bash title="turbo-notify.sh"
      https://api.turbonotify.com/v1/numbers/ALIAS_DO_NUMERO/connect \
      -H "Authorization: Bearer SUA_CHAVE"
    ```

A resposta confirma apenas que a **transição foi aceita**: o número entra
em estado `connecting` (`at` vem vazio nesta chamada). O status final
(`connected` ou `failed`) chega via webhook `number.connected` /
`number.connect.failed`, ou consultando o [Status dos números extras](/numbers/status/).

<ApiResponse
  status={200}
  body={{
    status: 'disconnecting',
    at: '',
  }}
/>

`disconnecting` é um literal de **confirmação de aceite** exclusivo desta
resposta, diferente de `connecting`: ele não é um dos valores da
[Tabela de status](/numbers/status/#tabela-de-status) e não aparece em
`GET /v1/numbers/{alias}` (que, logo após esta chamada, ainda mostra o
status anterior até o Turbo Notify concluir a desconexão). O status final
(`disconnected`) chega via webhook `number.disconnected`, ou consultando
o [Status dos números extras](/numbers/status/).

:::note[Ativação e desativação do número principal]
O número principal tem suas próprias rotas, sem `{alias}` no path e com
resposta mais simples (só `alias` e `status`, sem o campo `at`):

- `POST /v1/numbers/main/connect` → `202 Accepted`, `{"alias": "main", "status": "connecting"}`
- `POST /v1/numbers/main/disconnect` → `202 Accepted`, `{"alias": "main", "status": "disconnecting"}`

Nenhuma das duas depende do plano: estão sempre disponíveis, independente
do tier. Ambas retornam `422 no_main_number_configured` quando não há número
principal cadastrado na conta, e `422 main_number_not_paired` quando o
número existe mas ainda não concluiu o pareamento (pareie pelo dashboard
primeiro). Erros adicionais: `409 already_connected`,
`409 already_connecting` no connect; `422 no_active_session` no
disconnect.
:::

## Erros possíveis

### Ativação (`POST /v1/numbers/{alias}/connect`)

| Status | Código de erro              | Descrição                                                     |
| :----: | ---------------------------- | ------------------------------------------------------------- |
| `402`  | `subscription_inactive`      | A assinatura da organização está `past_due`, `terminated`, `pending` ou com trial expirado (resposta inclui `details.status`). |
| `402`  | `feature_not_available`      | O plano atual não suporta números extras.                     |
| `403`  | `no_device_link`             | O número extra não tem um vínculo de dispositivo ativo (estado inconsistente). |
| `403`  | `extra_number_not_paired`    | O número extra ainda não concluiu o pareamento. Chame `POST /v1/numbers/{alias}/pair` primeiro. |
| `404`  | `extra_number_not_found`     | O alias informado não corresponde a nenhum número cadastrado. |
| `409`  | `already_connected`          | O número extra já está conectado.                              |
| `409`  | `already_connecting`         | Já existe uma tentativa de conexão em andamento.                |
| `500`  | `internal_error`             | Erro interno inesperado no servidor.                           |

### Desativação (`POST /v1/numbers/{alias}/disconnect`)

| Status | Código de erro          | Descrição                                                     |
| :----: | ------------------------ | ------------------------------------------------------------- |
| `402`  | `feature_not_available`  | O plano atual não suporta números extras.                     |
| `404`  | `extra_number_not_found` | O alias informado não corresponde a nenhum número cadastrado. |
| `422`  | `no_active_session`      | O número extra já não está conectado (nada a desconectar).    |
| `500`  | `internal_error`         | Erro interno inesperado no servidor.                           |

Ambas as rotas também retornam `403 not_authorized` (chave inválida/ausente)
e `403 insufficient_scope` (falta o escopo `numbers:write`, resposta inclui
`required_scope`) como qualquer outro endpoint autenticado.
