Números extras permitem que você envie mensagens a partir de múltiplos números de WhatsApp, além do número principal da sua conta. Cada número extra é vinculado via código de pareamento.

## Cadastro pelo dashboard

A forma mais simples de adicionar um número extra é pelo dashboard do Turbo Notify. Acesse a página de <DashboardLink path="/numbers">Números Extras</DashboardLink> e clique em **Adicionar número**.

Você deverá informar o número de telefone com código do país e aguardar o código de pareamento que será exibido na tela. Insira esse código no WhatsApp do aparelho correspondente para concluir a vinculação.

O cadastro (`POST /v1/numbers`) e o pareamento (obtenção do código a ser
inserido no WhatsApp) são **operações separadas**. A resposta do cadastro
confirma apenas a criação do número — o `status` sempre nasce `"pending"` e
não há código de pareamento inline:

<ApiResponse
  status={201}
  body={{
    alias: 'vendas_sp',
    phone_number: '+5511988888888',
    status: 'pending',
    created_at: '2025-07-16T10:00:00Z',
    description: null,
  }}
/>

## Obtendo o código de pareamento

Depois de criar o número, chame `POST /v1/numbers/{alias}/pair` para
disparar a geração do código e obtê-lo:

<ApiResponse
  status={202}
  body={{
    alias: 'vendas_sp',
    status: 'pairing',
  }}
/>

Números extras sempre pareiam por **código de vinculação** (`pairing_code`)
— QR code é exclusivo do número principal. O código em si é entregue de
forma assíncrona — consulte [Status dos Números Extras](/numbers/status/),
cujo bloco `pairing` traz `{method, data, expires_at}` enquanto `status` é
`"pairing"`.

## Usabilidade

- Cada número extra deve pertencer a um aparelho com WhatsApp ativo.
- O código de pareamento tem validade limitada. Caso expire, será necessário refazer a solicitação de pareamento.
- Você pode definir um alias para o número extra durante o cadastro, facilitando o uso no envio de mensagens via URL (`/v1/numbers/{alias}/...`).
- O número nasce com status `pending` e só avança para `pairing` após a chamada de pareamento.

## Status

Após cadastrar o número extra, acompanhe o andamento da vinculação consultando o [Status dos Números Extras](/numbers/status/).

## Erros possíveis

Veja os principais erros que podem ocorrer no cadastro de números extras:

| Status | Código de erro           | Descrição                                              |
| :----: | ------------------------ | ------------------------------------------------------ |
| `400`  | `invalid_json`           | O JSON da requisição está malformado ou inválido.      |
| `400`  | `reserved_alias`         | O alias `"main"` é reservado para o número principal e não pode ser usado em um número extra. |
| `402`  | `feature_not_available`  | O plano atual não suporta números extras.              |
| `402`  | `extra_numbers_limit_reached` | A organization já atingiu o teto de números extras do tier (BUSINESS 300 / CUSTOM 1.000). A resposta inclui `details.limit` e `details.current`. |
| `403`  | `not_authorized`         | A chave de acesso está inválida ou ausente.            |
| `403`  | `insufficient_scope`     | A chave de acesso não possui o escopo `numbers:write` (resposta inclui `required_scope`). |
| `409`  | `number_already_exists`  | O alias ou o número informado já está cadastrado na conta. |
| `500`  | `internal_error`         | Erro interno inesperado no servidor.                   |
| `503`  | `whatsapp_unavailable`   | O WhatsApp está temporariamente fora do ar.            |
