Remova números extras que não são mais necessários para liberar vagas no seu plano e encerrar a cobrança correspondente.

## O que acontece no celular

Quando a remoção é concluída (na hora ou no fim do ciclo, se foi agendada), o
Turbo Notify desconecta o número do WhatsApp: a entrada com o nome da sua
organização some de **Dispositivos conectados** no celular do número, em
geral em poucos minutos. Se o celular estiver sem internet, isso acontece
assim que ele voltar a se conectar. Os dados de acesso ao WhatsApp desse
número são apagados da sua conta.

## Cobrança

O efeito na fatura depende de qual dos dois caminhos de remoção foi tomado:

- **Remoção imediata**: remover um número extra logo depois de adicioná-lo, antes de usá-lo, pode excluí-lo na hora e **reembolsar automaticamente** a cobrança pro-rata feita na ativação. Ele não entra na fatura do próximo ciclo.
- **Remoção agendada**: nos demais casos, o número continua ativo até o **fim do ciclo pago do número** (veja `scheduled_deletion_at` na resposta), com status `pending_deletion`, e então é removido. **Um novo ciclo que comece nesse intervalo ainda o cobra pelo valor cheio de renovação**, exatamente como um número apenas desconectado. A cobrança só para quando a exclusão é executada. Até lá, você pode [cancelar a exclusão](#cancelar-exclusão-agendada).

A resposta do `DELETE` diz o que aconteceu, em `refund_eligible`, `refund_amount_cents`, `refund_status` e `scheduled_deletion_at`. Dúvidas sobre um reembolso: escreva para billing@turbonotify.com. Para mais detalhes, consulte [Cobrança de números extras](/numbers/billing/).

## Remover pelo dashboard

Acesse a página de <DashboardLink path="/numbers">Números</DashboardLink> no dashboard, abra o número desejado e clique em **Remover número**. Antes de confirmar, o painel mostra o que vai acontecer: a remoção imediata, com o valor da ativação que será reembolsado quando houver (botão **Remover**), ou a exclusão agendada para o fim do período já pago, sem reembolso (botão **Agendar exclusão**).

<ApiResponse
  status={200}
  body={{
    scheduled_deletion_at: '2025-07-16T10:00:00Z',
    refund_eligible: true,
    refund_amount_cents: 2252,
    refund_status: 'succeeded',
  }}
/>

**Escopo obrigatório:** `numbers:write`

A resposta descreve o **resultado da exclusão**, não o número em si:

| Campo | Tipo | Descrição |
| ----- | ---- | --------- |
| `scheduled_deletion_at` | string | Timestamp ISO 8601 de quando o número é removido da conta. |
| `refund_eligible` | boolean | `true` quando a remoção foi **imediata** e a cobrança de ativação é reembolsada; nesse caso `scheduled_deletion_at` é o momento atual. `false` quando a exclusão foi agendada; nesse caso `scheduled_deletion_at` fica no **fim do ciclo pago do número**. |
| `refund_amount_cents` | integer | Valor reembolsado em centavos: o mesmo valor da cobrança pro-rata feita na ativação deste número. `0` quando `refund_eligible` é `false`, ou quando `refund_status` é `not_applicable` ou `failed` (veja abaixo). |
| `refund_status` | string \| null | O resultado da tentativa de reembolso: `succeeded` (reembolso processado; `refund_amount_cents` traz o valor reembolsado), `not_applicable` (nada a reembolsar nesta resposta: não havia cobrança de ativação para este número, ou outra requisição simultânea para o mesmo número já está cuidando do reembolso; não é um erro) ou `failed` (havia uma cobrança e o reembolso não pôde ser processado; a exclusão do número **não é bloqueada por isso**. Escreva para billing@turbonotify.com para receber o reembolso). `null` quando `refund_eligible` é `false` (nenhum reembolso foi tentado). |

A chamada é **idempotente**: repetir a requisição para um número já agendado
para exclusão retorna o mesmo agendamento (sem gerar um novo reembolso).

## Cancelar exclusão agendada

Enquanto o número estiver em `pending_deletion` (exclusão ainda não
executada), você pode cancelar e manter o número normalmente.

:::caution[Pode gerar cobrança]
Cancelar a exclusão agendada de um número extra (por esta chamada ou reconectando o número) pode gerar cobrança: quando o número foi criado antes do início do ciclo cobrado atual, a taxa de ativação é cobrada de novo para trazê-lo de volta. Veja [Cobrança de números extras](/numbers/billing/).
:::

## Erros possíveis

### Remover (`DELETE /v1/numbers/{alias}`)

| Status | Código de erro                 | Descrição                                           |
| :----: | -------------------------------- | --------------------------------------------------- |
| `400`  | `invalid_status_for_deletion`   | O número está `connected`. Desconecte antes de agendar a exclusão. |
| `402`  | `feature_not_available`  | O plano atual não suporta números extras.           |
| `401`  | `not_authenticated`      | A chave de acesso está inválida ou ausente.         |
| `403`  | `insufficient_scope`     | A chave de acesso não possui o escopo `numbers:write` (resposta inclui `required_scope`). |
| `404`  | `extra_number_not_found` | O alias informado não foi encontrado na conta.      |
| `500`  | `internal_error`         | Erro interno inesperado no servidor.                |

### Cancelar exclusão (`POST /v1/numbers/{alias}/cancel-deletion`)

| Status | Código de erro           | Descrição                                              |
| :----: | ------------------------- | ------------------------------------------------------ |
| `400`  | `not_pending_deletion`   | O número não está com exclusão agendada.                |
| `400`  | `no_payment_method`      | O cancelamento exige cobrança de reativação, mas a organização não tem forma de pagamento cadastrada. A exclusão continua agendada. |
| `402`  | `feature_not_available`  | O plano atual não suporta números extras.               |
| `402`  | `payment_declined`       | A cobrança de reativação foi recusada. A exclusão continua agendada. |
| `402`  | `payment_requires_authentication` | A forma de pagamento exige reautenticação (3DS). A exclusão continua agendada. |
| `401`  | `not_authenticated`      | A chave de acesso está inválida ou ausente.              |
| `403`  | `insufficient_scope`     | A chave de acesso não possui o escopo `numbers:write` (resposta inclui `required_scope`). |
| `404`  | `extra_number_not_found` | O alias informado não foi encontrado na conta.           |
| `500`  | `internal_error`         | Erro interno inesperado no servidor.                     |
| `503`  | `payment_gateway_unavailable` | A cobrança de reativação não pôde ser confirmada a tempo. Tente novamente. |
