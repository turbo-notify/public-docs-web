Remova números extras que não são mais necessários para liberar vagas no seu plano e encerrar a cobrança correspondente.

## Cobrança

O efeito na fatura depende de qual dos dois caminhos de remoção foi tomado:

- **Remoção imediata** (elegível a reembolso: menos de **72 horas** desde a primeira conexão **e** menos de **10 mensagens** enviadas) — o número é excluído na hora e **não entra na fatura** do ciclo em curso.
- **Remoção agendada** — o número permanece na conta durante os **30 dias** de espera, então **qualquer ciclo que feche nesse intervalo ainda o cobra pro-rata**, exatamente como um número apenas desconectado. A cobrança só cessa quando a exclusão é de fato executada.

O campo `refund_eligible` na resposta do `DELETE` informa qual caminho foi tomado (`true` = remoção imediata). Para mais detalhes, consulte a documentação de [Cobrança de números extras](/numbers/billing/).

## Remover pelo dashboard

Acesse a página de <DashboardLink path="/numbers">Números</DashboardLink> no dashboard, localize o número desejado e clique em **Remover**. Confirme a ação na caixa de diálogo.

<ApiResponse
  status={200}
  body={{
    scheduled_deletion_at: '2025-07-16T10:00:00Z',
    refund_eligible: true,
    refund_amount_cents: 0,
    messages_sent: 3,
  }}
/>

**Escopo obrigatório:** `numbers:write`

A resposta descreve o **resultado da exclusão**, não o número em si:

| Campo | Tipo | Descrição |
| ----- | ---- | --------- |
| `scheduled_deletion_at` | string | Timestamp ISO 8601 de quando a exclusão (soft-delete) acontece. |
| `refund_eligible` | boolean | `true` quando o número se qualifica para reembolso imediato (janela de 72h, poucas mensagens enviadas) — nesse caso a exclusão é **imediata** e `scheduled_deletion_at` é o momento atual. `false` quando a exclusão é agendada — nesse caso `scheduled_deletion_at` fica **30 dias** à frente. |
| `refund_amount_cents` | integer | Valor reembolsado em centavos. **Hoje é sempre `0`**, inclusive quando `refund_eligible` é `true` — o cálculo de valores monetários de reembolso ainda não é feito pela API. |
| `messages_sent` | integer | Total de mensagens já enviadas por este número — usado para determinar elegibilidade de reembolso. |

A chamada é **idempotente**: repetir a requisição para um número já agendado
para exclusão retorna o mesmo agendamento (sem gerar um novo reembolso).

## Cancelar exclusão agendada

Enquanto o número estiver em `pending_deletion` (exclusão ainda não
executada), você pode cancelar e manter o número normalmente.

`status` aqui é um **literal de confirmação** ("a exclusão pendente foi

`disconnecting` em [Ativação e

necessário desconectar o número antes de agendar a exclusão), consulte o

## Erros possíveis

### Remover (`DELETE /v1/numbers/{alias}`)

| Status | Código de erro                 | Descrição                                           |
| :----: | -------------------------------- | --------------------------------------------------- |
| `400`  | `invalid_status_for_deletion`   | O número está `connected` — desconecte antes de agendar a exclusão. |
| `402`  | `feature_not_available`  | O plano atual não suporta números extras.           |
| `403`  | `not_authorized`         | A chave de acesso está inválida ou ausente.         |
| `403`  | `insufficient_scope`     | A chave de acesso não possui o escopo `numbers:write` (resposta inclui `required_scope`). |
| `404`  | `extra_number_not_found` | O alias informado não foi encontrado na conta.      |
| `500`  | `internal_error`         | Erro interno inesperado no servidor.                |

### Cancelar exclusão (`POST /v1/numbers/{alias}/cancel-deletion`)

| Status | Código de erro           | Descrição                                              |
| :----: | ------------------------- | ------------------------------------------------------ |
| `400`  | `not_pending_deletion`   | O número não está com exclusão agendada.                |
| `402`  | `feature_not_available`  | O plano atual não suporta números extras.               |
| `403`  | `not_authorized`         | A chave de acesso está inválida ou ausente.              |
| `403`  | `insufficient_scope`     | A chave de acesso não possui o escopo `numbers:write` (resposta inclui `required_scope`). |
| `404`  | `extra_number_not_found` | O alias informado não foi encontrado na conta.           |
| `500`  | `internal_error`         | Erro interno inesperado no servidor.                     |
