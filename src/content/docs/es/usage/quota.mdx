> Esta página está siendo traducida. Consulte la versión canónica en PT-BR: [/usage/quota/](/usage/quota/).

**A nivel de cuenta** (permanecen en la raíz, sin cambios):

```http title="Uso a nivel de cuenta"
GET /v1/usage
GET /v1/usage/messages
```

**Cuota de contactos — ahora por número:**

```http title="Cuota de contactos del número"
GET /v1/numbers/{alias}/contacts/quota
```

`{alias}` es `main` o el alias de un número extra. La cuota de contactos es **por número**. Para el número principal también puedes usar la ruta plana `GET /v1/contacts/quota`; para números extra usa `GET /v1/numbers/{alias}/contacts/quota`.
