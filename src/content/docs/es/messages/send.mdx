> Esta página está siendo traducida. Consulte la versión canónica en PT-BR: [/messages/send/](/messages/send/).

```http title="Enviar mensaje"
POST /v1/numbers/{alias}/messages
```

`{alias}` es `main` (número principal) o el alias de un número extra — **es el remitente**. El campo `from` en el body fue **eliminado**.

- `to`: exactamente uno de `{ "number": "…" }`, `{ "group_id": "grp_…" }` o `{ "contact_id": "ct_…" }`.
- `content`: objeto anidado con el contenido del mensaje (texto, media, etc.).

Para enviar desde el número principal use la ruta plana `POST /v1/messages` (sin `{alias}`). Para números extra use `POST /v1/numbers/{alias}/messages`. Para responder a un mensaje recibido: `POST /v1/messages/{id}/reply`.

## Menciones (@mentions)

Desde 2026-07-03, escriba tokens **`@<numero>`** directamente en `content.text` (o en el `caption` de media — imagen/video/documento; audio/sticker no tienen caption) para producir una **mención real de WhatsApp** (nombre tocable + notificación en el dispositivo del mencionado): `@` seguido del teléfono del contacto en dígitos E.164 **sin `+`**.

```bash
curl -X POST https://api.turbonotify.com/v1/messages \
  -H "Authorization: Bearer tn_live_..." \
  -H "Content-Type: application/json" \
  -d '{
    "to": { "group_id": "grp_e442553a56b14e2695f6acfd7d651b1a" },
    "content": { "text": "Buenos días @5511987650000, ¡su pedido llegó!" }
  }'
```

La detección es **implícita** — no existe un campo `mentions` en el request. Dígitos inválidos o no canonicalizables (emails, `@+55…`, más de 15 dígitos) quedan como texto plano — el envío nunca falla por una mención (fail-open). Los tokens brasileños de 12 dígitos se normalizan a la forma canónica de 13 dígitos en el contenido almacenado/público. Funciona en chats 1:1 y grupos, y nunca consume cuota de mensajes ni de contactos. El mensaje resultante lleva un array `mentions` hidratado (ítems `{contact_id?, name?, number}`) en `GET …/messages/{id}` y en el `data` de los eventos `message.sent`/`replied`/`edited`; un token `@<numero>` recibido puede pegarse de vuelta en un envío (simetría de eco).
