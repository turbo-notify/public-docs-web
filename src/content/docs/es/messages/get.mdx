> Esta página está siendo traducida. Consulte la versión canónica en PT-BR: [/messages/get/](/messages/get/).

```http title="Consultar mensaje"
GET /v1/numbers/{alias}/messages/{id}
```

`{alias}` es el `number_alias` recibido en el envelope del evento (`main` o el alias de un número extra); `{id}` es el `msg_…`. Acceder a un `id` bajo el alias equivocado devuelve **404**.

Sub-rutas relacionadas: `/status`, `/reactions`, `/receipts`. El `at` de nivel raíz es el momento de ocurrencia **estable**; `status.at` **avanza** con cada transición de entrega. Para el número principal use la ruta plana `GET /v1/messages/{id}`; para números extra use `GET /v1/numbers/{alias}/messages/{id}`.
