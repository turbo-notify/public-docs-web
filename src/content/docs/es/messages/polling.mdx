> Esta página está siendo traducida. Consulte la versión canónica en PT-BR: [/messages/polling/](/messages/polling/).

```http title="Polling de eventos"
GET /v1/events
GET /v1/events?number_alias={alias}
```

`GET /v1/events` es **a nivel de cuenta** y permanece en la raíz (no se anida bajo el número). Cada ítem lleva `number_alias` en el envelope (`main` o el alias de un número extra), salvo los eventos `storage.*` (toda familia `*.quota.*`, incluida `message.quota.*`, es por número desde la ADR 2026-07-02 y lo lleva). Acepta el filtro opcional `number_alias` para restringir la respuesta a un único número.

El `data` de cada evento es **byte-idéntico** al del webhook. Usa el `number_alias` del envelope para las llamadas por id posteriores (p. ej. `GET /v1/numbers/{alias}/messages/{id}`).

La paridad incluye **`data.mentions`** (desde 2026-07-03): cuando un mensaje menciona a alguien, los ítems `message.received`/`replied`/`sent`/`edited` del polling devuelven la misma lista `mentions` — y el mismo `preview` consciente de menciones (cada token cuenta como 1 carácter) — byte-idénticos a la entrega por webhook.
