---
title: Rutas planas para el número principal
description: Las rutas /v1/messages, /v1/contacts y /v1/groups ahora apuntan directamente al número principal, sin necesidad de especificar el alias.
sidebar:
  order: 7
---

A partir de esta versión, todas las operaciones del número principal pueden
realizarse directamente sin especificar el alias en la URL:

| Nueva ruta plana | Equivalente |
|---|---|
| `POST /v1/messages` | `POST /v1/numbers/main/messages` |
| `GET  /v1/messages` | `GET  /v1/numbers/main/messages` |
| `GET  /v1/messages/{id}` | `GET  /v1/numbers/main/messages/{id}` |
| `GET  /v1/contacts` | `GET  /v1/numbers/main/contacts` |
| `GET  /v1/contacts/quota` | `GET  /v1/numbers/main/contacts/quota` |
| `GET  /v1/groups` | `GET  /v1/numbers/main/groups` |
| `POST /v1/typing-indicator` | `POST /v1/numbers/main/typing-indicator` |
| *(y todas las sub-rutas)* | |

La forma `/v1/numbers/main/…` sigue funcionando con normalidad y produce
respuestas idénticas. Para **números extras**, continúa usando `/v1/numbers/{alias}/…`.

Este cambio no requiere ninguna modificación en integraciones existentes.
