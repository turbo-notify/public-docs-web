## Novedades

### `to.contact_id` como destinatario

`POST /v1/messages` ahora acepta `{"contact_id": "ct_…"}` como tercera forma mutuamente excluyente para el campo `to`, junto a `{"number": "…"}` y `{"group_id": "…"}`.

El número de teléfono se resuelve automáticamente desde el catálogo de Contactos TN.

**Nuevos códigos de error:**
- `contact_not_found` (HTTP 422) — el `contact_id` proporcionado no pertenece a este organization.
- `contacts_not_enabled` (HTTP 422) — funcionalidad no configurada en esta instancia.

## Corrección de Documentación

Los ejemplos de código mostraban `"to": "+5511999999999"` (cadena simple). El formato correcto siempre fue `"to": {"number": "+5511999999999"}`.
