> Esta página está siendo traducida. Consulte la versión PT-BR (canónica): [/groups/picture/](/groups/picture/).

```http title="Foto del grupo"
GET /v1/numbers/{alias}/groups/{id}/picture
```

`{alias}` es `main` o el alias de un número extra; `{id}` es el `grp_…` del grupo. Devuelve una URL presignada (302) o un cuerpo de unión (200) cuando no hay foto disponible. La ruta plana `GET /v1/groups/{id}/picture` está retirada (404).
