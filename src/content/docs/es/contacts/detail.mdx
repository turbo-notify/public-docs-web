```http title="Detalle de contacto"
GET /v1/numbers/{alias}/contacts/{id}
```

`{alias}` es `main` o el alias de un número extra; `{id}` es el `ct_…` recibido en el envelope del evento. Acceder a un `id` bajo el alias equivocado devuelve **404**. La ruta plana `GET /v1/contacts/{id}` está retirada.
