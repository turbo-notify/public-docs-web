> Esta página está siendo traducida. Consulte la versión canónica en PT-BR: [/contacts/profile-picture/](/contacts/profile-picture/).

```http title="Foto de perfil del contacto"
GET /v1/numbers/{alias}/contacts/{id}/profile-picture
```

`{alias}` es `main` o el alias de un número extra; `{id}` es el `ct_…` del contacto. Devuelve una URL presignada (302) o un cuerpo de unión cuando no hay foto disponible. Para el número principal use la ruta plana `GET /v1/contacts/{id}/profile-picture`; para números extra use `GET /v1/numbers/{alias}/contacts/{id}/profile-picture`.
