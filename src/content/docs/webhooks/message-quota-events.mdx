Eventos relacionados ao **quota mensal de mensagens por tier** (free=1k, solo=10k, business=50k, custom=500k+).

> **Nota (2026-05-15):** o enforcement deste quota foi ativado em 2026-05-15. Os limites já estavam documentados — a partir desta data, o código aplica os limites efetivamente. Veja [Per-Tier Message Quota Activation](/changelog/2026-05-15-message-quota-activation/) e a [auditoria em rate-limits](/messages/rate-limits/).

## Eventos

| Evento | Quando |
| ------ | ------ |
| `message.quota.warning` | Cruzou threshold 80/90/95% da quota mensal de mensagens |
| `message.quota.exceeded` | Tentativa rejeitada por estouro (HTTP 429) |

## Exemplo: `message.quota.warning`

```json
{
  "id": "evt_...",
  "type": "message.quota.warning",
  "organization_id": "org_a1b2c3d4e5f6a1b2c3d4e5f6a1b2c3d4",
  "created_at": "2026-05-15T12:00:00Z",
  "data": {
    "threshold_bps": 80,
    "used": 800,
    "quota": 1000,
    "resets_at": "2026-06-14T...",
    "tier": "free"
  }
}
```

## Exemplo: `message.quota.exceeded`

```json
{
  "id": "evt_...",
  "type": "message.quota.exceeded",
  "organization_id": "org_a1b2c3d4e5f6a1b2c3d4e5f6a1b2c3d4",
  "created_at": "2026-05-15T12:00:00Z",
  "data": {
    "quota": 1000,
    "used": 1000,
    "resets_at": "2026-06-14T...",
    "tier": "free"
  }
}
```

## Timestamps e correlação

- Estes são eventos **sintéticos** do Turbo Notify (não refletem uma ação no WhatsApp): desde 2026-06-02 **não** carregam `at` em `data` — apenas o `created_at` do envelope (momento de emissão do evento pelo TN).
- `resets_at` é um timestamp de **valor de negócio** (quando a janela de quota reinicia), mantido com seu nome semântico — não é o momento de ocorrência.
- Não há `phone` no payload destes eventos. Para correlacionar com a requisição que disparou o estouro, use `GET /v1/events?request_id=req_...`.
