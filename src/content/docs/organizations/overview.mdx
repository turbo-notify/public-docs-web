O Turbo Notify é **single-organization por chave de API**: cada chave pertence a exatamente uma organização, e estes dois endpoints só permitem ler os dados da **sua própria** organização — não há um diretório de organizações de terceiros.

**Escopo obrigatório:** `organizations:read` (selecionável na criação da chave de API no dashboard).

## Listar organização

`GET /v1/organizations` retorna sempre uma coleção de **um único item** — a
organização autenticada — no formato de lista padrão da API (`data`,
`cursor`, `has_more`). `cursor` é sempre `null` e `has_more` é sempre
`false`; não há paginação real aqui.

## Detalhe da organização

`GET /v1/organizations/{organization_id}` retorna o mesmo objeto, sem o
envelope de lista. O `{organization_id}` deve ser o `org_{hex32}` da
**própria** organização autenticada — qualquer outro valor (mesmo que seja
um `org_` válido de outra organização) retorna `404`, nunca vaza dados de
terceiros.

## Campos da resposta

| Campo | Tipo | Descrição |
| ----- | ---- | --------- |
| `id` | string | Identificador público da organização (`org_` + 32 hex) |
| `name` | string | Nome cadastrado da organização |
| `plan` | string | Identificador do plano contratado (ex.: `free`, `solo`, `business`, `custom`) |
| `locale` | string | Locale configurado (ex.: `pt-BR`, `en`) |
| `timezone` | string | Timezone IANA usado para exibir `created_at`/`updated_at` com offset em outras superfícies (ex.: `America/Sao_Paulo`) |
| `suspended_at` | string\|null | Timestamp ISO 8601 de suspensão; `null` quando a organização está ativa |
| `created_at` | string | Timestamp ISO 8601 de criação da organização |
| `updated_at` | string | Timestamp ISO 8601 da última atualização dos dados cadastrais |

Apenas campos seguros para exposição pública aparecem aqui — flags
administrativas de anti-ban e overrides de billing nunca são retornados por
este endpoint.

## Erros possíveis

| Status | Código de erro           | Descrição                                              |
| :----: | ------------------------- | -------------------------------------------------------- |
| `403`  | `not_authorized`          | A chave de acesso está inválida ou ausente.              |
| `403`  | `insufficient_scope`      | A chave de acesso não possui o escopo `organizations:read` (resposta inclui `required_scope`). |
| `404`  | `organization_not_found`  | *(apenas detalhe)* O `{organization_id}` informado não corresponde à organização autenticada. |
| `500`  | `internal_error`          | Erro interno inesperado no servidor.                     |
