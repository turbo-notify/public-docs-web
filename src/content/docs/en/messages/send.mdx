```http title="Send a message"
POST /v1/numbers/{alias}/messages
```

The **sender is the path number** — `{alias}` is `main` (primary number) or an
extra-number alias. The request body no longer has a `from` field.

- **`to`** — recipient, exactly one of `number`, `group_id` or `contact_id`.
- **`content`** — nested object describing the message (text, media, etc.).

```bash
curl -X POST https://api.turbonotify.com/v1/messages \
  -H "Authorization: Bearer tn_live_..." \
  -H "Content-Type: application/json" \
  -d '{
    "to": { "number": "+5511999999999" },
    "content": { "text": "Hello from Turbo Notify" }
  }'
```

To reply to a message, use `POST /v1/messages/{id}/reply`. The
`Idempotency-Key` scope is `(organization, number_alias, key)`. For extra
numbers use `POST /v1/numbers/{alias}/messages`.
