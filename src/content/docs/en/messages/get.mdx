```http title="Get a message"
GET /v1/numbers/{alias}/messages/{id}
```

Returns a single message by id (`msg_…`). `{alias}` is the message's
`number_alias` — read it from the event/webhook envelope or the send response.
Accessing an id under the wrong alias returns **404**.

- Top-level `at` = the **stable** occurrence moment (does not advance).
- `status.at` = the **current** delivery-status time (advances `sent → delivered → read`).

Related sub-resources: `.../{id}/status`, `.../{id}/reactions`, `.../{id}/receipts`.

When the message mentions someone (see [Mentions](/en/messages/send/#mentions-mentions)),
the response carries an optional **`mentions`** array — items
`{contact_id?, name?, number}` (the inbound `from` shape), in first-token
order, deduped — for inbound **and** outbound messages; omitted when there are
no mentions. An `@<digits>` run in the text/`preview` is a mention **only if**
its number is listed there. The field survives body retention, and in previews
each mention token counts as exactly **1 character** (the crop never splits a
token).

```bash
curl https://api.turbonotify.com/v1/messages/msg_0198d3c5a1b24d3e9f01a2b3c4d5e6f7 \
  -H "Authorization: Bearer tn_live_..."
```

For extra numbers: `GET /v1/numbers/{alias}/messages/{id}`
