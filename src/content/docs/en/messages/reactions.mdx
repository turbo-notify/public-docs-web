After a message is sent or received, you can look up all of its active reactions. Each phone number can have at most one active reaction per message. The latest reaction sent replaces the previous one.

This page covers **looking up** reactions. To send or remove a reaction, see [Send a reaction](/en/other-features/reaction/).

## Get reactions

To list a message's reactions, make a `GET` request with the `message_id` returned when you sent it.

**Endpoint:** `GET /v1/messages/{message_id}/reactions` for the main number. For extra numbers, use `GET /v1/numbers/{alias}/messages/{message_id}/reactions`, where `{alias}` is the message's `number_alias`.

**Required scope:** `messages:read`

**Path parameters:**

| Parameter    | Type   | Description                             |
| ------------ | ------ | --------------------------------------- |
| `alias` | string | *(extra number route only)* Alias of the number the message belongs to. |
| `message_id` | string | Public message identifier (`msg_{hex32}`) |

## Response structure

| Field                    | Type    | Description                                                              |
| ------------------------ | ------- | ------------------------------------------------------------------------ |
| `message_id`             | string  | Public message identifier.                                               |
| `reactions`              | array   | List of active reactions (one per phone number).                         |
| `reactions[].from`       | object  | Sender of the reaction.                                                  |
| `reactions[].from.number`| string  | Phone number of who reacted (without `+`).                               |
| `reactions[].from.contact_id` | string | Public contact identifier (`ct_{hex32}`). Omitted when not available. |
| `reactions[].from.name`  | string | Sender's name on WhatsApp. Omitted when not available.                          |
| `reactions[].emoji`      | string  | Reaction emoji.                                                          |
| `reactions[].at`         | string  | ISO 8601 date and time when the reaction was recorded.                   |
| `reactions[].direction`  | string  | `"inbound"` (reaction from a contact) or `"outbound"` (reaction from the organization's number). |

## Possible errors

| Status | Error code       | Description                                          |
| :----: | ---------------- | ---------------------------------------------------- |
| `401`  | `not_authenticated` | The API key is invalid or missing.                                |
| `403`  | `insufficient_scope` | The API key does not have the `messages:read` scope.             |
| `404`  | `not_found`         | The message was not found, belongs to another organization, is outside your plan's [content retention window](/en/messages/retention/), or (on the nested route `/numbers/{alias}/messages/.../reactions`) belongs to a number other than the alias in the URL: all of these cases return the same response, with no distinction. |
| `404`  | `message_not_found` | *(only on the shortcut route without `{alias}`, `GET /v1/messages/{id}/reactions`)* The `message_id` exists but belongs to an extra number, not to the main number. |
| `404` | `number_not_found` | *(only on the route with `{alias}`)* The alias in the URL does not match any registered number. |
| `500`  | `internal_error`    | Unexpected internal server error.                                 |
