```http title="Get a group's picture"
GET /v1/numbers/{alias}/groups/{id}/picture
```

Returns the group's picture (302 → presigned URL when stored, or a JSON
availability union with a `setup_hint`). `{alias}` is the group's `number_alias`
(`main` or an extra-number alias) — take it from the event envelope. Accessing an
id under the wrong alias returns **404**.

Related group routes: `GET /v1/numbers/{alias}/groups` (list) and
`GET /v1/numbers/{alias}/groups/{id}` (detail). The flat `/v1/groups...` routes
are retired.

```bash
curl https://api.turbonotify.com/v1/numbers/main/groups/grp_a1b2c3d4e5f6a1b2c3d4e5f6a1b2c3d4/picture \
  -H "Authorization: Bearer tn_live_..."
```
