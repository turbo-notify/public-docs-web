| Quota | Route | Scope |
| ----- | ----- | ----- |
| Account usage | `GET /v1/usage` | Account-wide (top-level) |
| Message quota | `GET /v1/usage/messages` | Account-wide (top-level) |
| Contact quota | `GET /v1/numbers/{alias}/contacts/quota` | Per-number |

Contact quota is now **per-number**: each number (`main` or an extra-number alias)
tracks its own contact quota, so it is queried under that number. The flat
`GET /v1/contacts/quota` route is retired (**404**).

Account-wide usage (`GET /v1/usage`, `GET /v1/usage/messages`) stays **top-level**
and was not affected by the number-nested route change.
