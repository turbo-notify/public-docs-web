Changes that affect your integration are listed here, newest first. Changes that need action on your side are marked as such.

## October 2026: launch

- **WhatsApp API**: sending text, media, location, contact, calendar event and link button; replies, reactions, editing and deleting; delivery and read receipts; contacts and groups per number. See the [Quickstart](/en/guides/quickstart/).
- **Events** by signed [webhook](/en/messages/webhook/) or by [polling](/en/messages/polling/), in the same format.
- **MCP server** with 32 tools for AI agents, authenticated with your key. See [Build an AI agent](/en/guides/ai-agent/).
- **Resale**: extra numbers with `external_id`, `status` and `external_id` filters on the number list, `external_id` on every `number.*` event and the **Resale** key template. See [Resell to your customers](/en/guides/resale/).
- **Interactive API reference**, [error code index](/en/reference/errors/) and [Insomnia collection](/en/reference/api/#insomnia-collection).
- Documentation in Portuguese and English.
