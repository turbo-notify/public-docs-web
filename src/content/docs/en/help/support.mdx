## To get it solved faster

Include in your message:

- Your account email and the alias of the number involved (`main` or the extra number's alias).
- The error code and the full API response, or the event `id` (`evt_…`) and the `message_id` (`msg_…`) when it is about a message.
- The approximate time, with time zone.

Never send your API key. If it leaked, revoke it in the dashboard and create a new one (see [API key](/en/general/access-key/)).
