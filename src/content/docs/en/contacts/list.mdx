```http title="List contacts"
GET /v1/numbers/{alias}/contacts
```

Lists the contacts of a single number. Supports cursor pagination.

```bash
curl https://api.turbonotify.com/v1/contacts \
  -H "Authorization: Bearer tn_live_..."
```

For extra numbers: `GET /v1/numbers/{alias}/contacts`
