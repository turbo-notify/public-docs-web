List the contacts of a number, with filters and cursor pagination. Items come from the most recently updated to the oldest.

Each contact belongs to a number: `{alias}` is `main` (main number) or the alias of an extra number, and the same phone reached by two different numbers corresponds to two distinct contacts.

## Endpoint

```http
GET /v1/contacts?limit=20&cursor=<opaque>
```

For extra numbers: `GET /v1/numbers/{alias}/contacts?limit=20&cursor=<opaque>`

:::tip[Using extra numbers?]
To list the contacts of an extra number, use `/v1/numbers/{alias}/contacts` where
`{alias}` is the alias of your extra number. [Learn more](/en/numbers/add/).
:::

**Required scope:** `contacts:read`.

## Query parameters

| Parameter | Type | Description |
| --------- | ---- | ----------- |
| `limit` | int | 1 to 200 (default 50) |
| `cursor` | string | Opaque token returned in `cursor` |
| `phone` | string | Exact match on E.164 (`+5511...`) |
| `name` | string | Partial match on the contact name |
| `source` | enum | `inbound \| outbound \| self \| mention`: `mention` is a contact first seen because it was **mentioned** in a message; contacts created by a mention do **not** take a slot of the contact quota |
| `contacted_in_cycle` | bool | Returns only the contacts you talked to through Turbo Notify within the current billing cycle (new or returning). A send that did not reach WhatsApp does not count |

Each item is the same object returned by [Detail](/en/contacts/detail/). The
`phone_number` is the **full E.164** (unmasked). The contact has its own
dates (`created_at`, `updated_at`, `first_messaged_at` and the others), which
do not repeat the dates of an event.

`first_messaged_at` is when the first message from this number through Turbo Notify
reached the contact on WhatsApp, and `last_interaction_at` is the last message
actually exchanged with them, in either direction. `refresh` shows the last
[refresh request](/en/contacts/refresh/) you made (`null` if you never made one). The
details of each field are in [Detail](/en/contacts/detail/).
