Errors returned by the number-scoped contact endpoints
(`GET /v1/numbers/{alias}/contacts...`).

| Code | HTTP | Meaning |
| ---- | ---- | ------- |
| `contact_not_found` | 422 / 404 | The `contact_id` does not exist under this `{alias}`. |
| `contacts_not_enabled` | 422 | Contacts feature not configured on this deployment. |
| `number_not_found` | 404 | The `{alias}` is not a number of this organization. |

Note: a contact id accessed under the **wrong** `{alias}` returns **404** — ids are
globally unique but not alone-addressable (the `{alias}` or flat route is required).
For the primary number the flat routes (`/v1/contacts/{id}` etc.) are also available;
for extra numbers always use the nested form with the correct `{alias}`.
