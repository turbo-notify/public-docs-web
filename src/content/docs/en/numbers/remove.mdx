Remove extra numbers you no longer need to free up room in your plan and stop the matching charge.

## What happens on the phone

When the removal completes (right away, or at the end of the cycle if it was
scheduled), Turbo Notify disconnects the number from WhatsApp: the entry with
your organization's name disappears from **Linked devices** on the number's
phone, usually within a few minutes. If the phone is offline, this happens as
soon as it reconnects. The WhatsApp access data of this number is deleted
from your account.

## Billing

The effect on the invoice depends on which of the two removal paths was taken:

- **Immediate removal**: removing an extra number right after adding it, before using it, may delete it on the spot and **automatically refund** the pro-rata charge made at activation. It is not included in the next cycle's invoice.
- **Scheduled removal**: in every other case, the number stays active until the **end of the number's paid cycle** (see `scheduled_deletion_at` in the response), with status `pending_deletion`, and is then removed. **A new cycle that starts in that interval still charges it the full renewal price**, exactly like a number that is only disconnected. Billing stops only when the deletion runs. Until then, you can [cancel the deletion](#cancel-a-scheduled-deletion).

The `DELETE` response tells you what happened, in `refund_eligible`, `refund_amount_cents`, `refund_status` and `scheduled_deletion_at`. Questions about a refund: write to billing@turbonotify.com. For more details, see [Extra number billing](/en/numbers/billing/).

## Removing in the dashboard

Open the <DashboardLink path="/numbers">Numbers</DashboardLink> page in the dashboard, open the number and click **Remove number**. Before you confirm, the panel shows what will happen: immediate removal, with the activation amount that will be refunded when there is one (**Remove** button), or a deletion scheduled for the end of the period already paid, with no refund (**Schedule deletion** button).

<ApiResponse
  status={200}
  body={{
    scheduled_deletion_at: '2025-07-16T10:00:00Z',
    refund_eligible: true,
    refund_amount_cents: 2252,
    refund_status: 'succeeded',

**Required scope:** `numbers:write`

The response describes the **outcome of the deletion**, not the number itself:

| Field | Type | Description |
| ----- | ---- | ----------- |
| `scheduled_deletion_at` | string | ISO 8601 timestamp of when the number is removed from the account. |
| `refund_eligible` | boolean | `true` when the removal was **immediate** and the activation charge is refunded; in that case `scheduled_deletion_at` is the current time. `false` when the deletion was scheduled; in that case `scheduled_deletion_at` is at the **end of the number's paid cycle**. |
| `refund_amount_cents` | integer | Refunded amount in cents: the same amount as the pro-rata charge made when this number was activated. `0` when `refund_eligible` is `false`, or when `refund_status` is `not_applicable` or `failed` (see below). |
| `refund_status` | string \| null | The outcome of the refund attempt: `succeeded` (refund processed; `refund_amount_cents` has the refunded amount), `not_applicable` (nothing to refund in this response: there was no activation charge for this number, or another simultaneous request for the same number is already handling the refund; not an error) or `failed` (there was a charge and the refund could not be processed; the deletion of the number **is not blocked by this**. Write to billing@turbonotify.com to get the refund). `null` when `refund_eligible` is `false` (no refund was attempted). |

The call is **idempotent**: repeating the request for a number already
scheduled for deletion returns the same schedule (without a new refund).

## Cancel a scheduled deletion

While the number is in `pending_deletion` (deletion not yet carried out), you
can cancel it and keep the number as usual.

:::caution[May trigger a charge]
Canceling the scheduled deletion of an extra number (through this call or by reconnecting the number) may trigger a charge: when the number was created before the start of the current billed cycle, the activation fee is charged again to bring it back. See [Extra number billing](/en/numbers/billing/).
:::

## Possible errors

### Remove (`DELETE /v1/numbers/{alias}`)

| Status | Error code                       | Description                                         |
| :----: | -------------------------------- | --------------------------------------------------- |
| `400`  | `invalid_status_for_deletion`   | The number is `connected`. Disconnect it before scheduling the deletion. |
| `402`  | `feature_not_available`  | The current plan does not support extra numbers.    |
| `401`  | `not_authenticated`      | The API key is invalid or missing.                  |
| `403`  | `insufficient_scope`     | The API key does not have the `numbers:write` scope (the response includes `required_scope`). |
| `404`  | `extra_number_not_found` | The alias was not found in the account.             |
| `500`  | `internal_error`         | Unexpected internal server error.                   |

### Cancel deletion (`POST /v1/numbers/{alias}/cancel-deletion`)

| Status | Error code                | Description                                            |
| :----: | ------------------------- | ------------------------------------------------------ |
| `400`  | `not_pending_deletion`   | The number does not have a scheduled deletion.          |
| `400`  | `no_payment_method`      | Canceling requires a reactivation charge, but the organization has no payment method on file. The deletion stays scheduled. |
| `402`  | `feature_not_available`  | The current plan does not support extra numbers.        |
| `402`  | `payment_declined`       | The reactivation charge was declined. The deletion stays scheduled. |
| `402`  | `payment_requires_authentication` | The payment method requires re-authentication (3DS). The deletion stays scheduled. |
| `401`  | `not_authenticated`      | The API key is invalid or missing.                      |
| `403`  | `insufficient_scope`     | The API key does not have the `numbers:write` scope (the response includes `required_scope`). |
| `404`  | `extra_number_not_found` | The alias was not found in the account.                 |
| `500`  | `internal_error`         | Unexpected internal server error.                       |
| `503`  | `payment_gateway_unavailable` | The reactivation charge could not be confirmed in time. Try again. |
