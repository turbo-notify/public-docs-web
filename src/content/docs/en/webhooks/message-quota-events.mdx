The `message.quota.warning` and `message.quota.exceeded` events are **account-wide
(per-organization)**: message quota is not scoped to a single number, so these
events do **not** carry `number_alias` in the envelope.

This contrasts with `contact.quota.*`, which became **per-number** and now carries
`number_alias` (see [Contact events](/webhooks/contact-events/)). `number_alias` is
omitted only on `storage.*` and `message.quota.*`.
