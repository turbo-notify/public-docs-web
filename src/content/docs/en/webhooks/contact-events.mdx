All `contact.*` events carry **`number_alias`** in the envelope (immediately below
`organization_id`), identifying the number the contact belongs to. Use that alias
on by-id calls, e.g. `GET /v1/numbers/{alias}/contacts/{id}`.

## `contact.quota.*` is per-number

As of 2026-06-22, `contact.quota.warning` and `contact.quota.exceeded` are
**per-number** and **DO** carry `number_alias` in the envelope, identifying the
number whose contact quota was reached. The event `data` is unchanged.

```json title="contact.quota.warning envelope"
{
  "event_id": "evt_…",
  "type": "contact.quota.warning",
  "organization_id": "org_…",
  "number_alias": "main",
  "created_at": "2026-06-22T10:00:00Z",
  "data": { /* unchanged */ }
}
```

`number_alias` is omitted **only** on `storage.*` and the message-quota events
(`message.quota.*`) — account-wide events with no single number.
