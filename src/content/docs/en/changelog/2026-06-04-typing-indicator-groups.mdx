## What's New

### Group support in typing indicator

`POST /v1/typing-indicator` now accepts `{"group_id": "grp_…"}` as a recipient, in addition to the existing `{"number": "…"}`. `contact_id` is not supported for typing indicators.

**New error codes:**
- `group_not_found` (HTTP 422) — the supplied `group_id` does not belong to this tenant.
- `groups_not_enabled` (HTTP 422) — the Groups feature is not enabled on this deployment.
