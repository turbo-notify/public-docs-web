Acompanhe o status de cada número extra cadastrado na sua conta para garantir que estejam ativos e prontos para envio.

## Cobrança

A cobrança de números extras é feita de forma proporcional ao período de uso. Para entender os valores e o ciclo de cobrança, consulte a documentação de [Cobrança de Números Extras](/extra-numbers/billing/).

## Consultar status

Para verificar o status de um número extra específico, faça uma requisição GET informando o alias do número.

## Campos da resposta

| Campo | Tipo | Descrição |
| ----- | ---- | --------- |
| `alias` | string | Identificador único do número extra na conta |
| `phone_number` | string | Número de telefone no formato E.164 |
| `name` | string\|null | Nome da conta WhatsApp do número (capturado na conexão); `null` enquanto não houver conexão estabelecida |
| `number_type` | string | Sempre `"extra"` para números extras |
| `status` | string | Estado atual — veja tabela abaixo |
| `at` | string | Timestamp ISO 8601 da última mudança de status |
| `description` | string\|null | Descrição livre definida pelo usuário |
| `scheduled_deletion_at` | string\|null | Timestamp ISO 8601 da exclusão programada; `null` se não agendado |
| `reason` | string\|null | Motivo de falha quando `status = "failed"`; `null` caso contrário |
| `pairing` | object\|null | Informações de pareamento — presente apenas durante o processo de vinculação |

### Bloco de pareamento (`pairing`)

Presente quando `status` é `pairing` e o código ainda está válido:

| Campo | Tipo | Descrição |
| ----- | ---- | --------- |
| `method` | string | Método de pareamento: `"pairing_code"` |
| `data` | string | Código de 8 dígitos a ser inserido no WhatsApp |
| `expires_at` | string | Timestamp ISO 8601 de expiração do código |

## Tabela de status

| Status     | Descrição                                                        |
| ---------- | ---------------------------------------------------------------- |
| `pending`  | Número cadastrado; aguardando início do pareamento.              |
| `pairing`  | Código de pareamento gerado; aguardando inserção no WhatsApp.    |
| `active`   | O número está vinculado e pronto para envio de mensagens.        |
| `inactive` | O número foi desativado manualmente e não pode enviar mensagens. |
| `failed`   | A vinculação falhou. Verifique o motivo abaixo.                  |
| `revoked`  | O dispositivo foi desvinculado pelo WhatsApp.                    |

## Motivos de falha

Quando o status é `failed`, o campo `reason` indica o motivo:

| Motivo                  | Descrição                                                     |
| ----------------------- | ------------------------------------------------------------- |
| `invalid_code`          | O código de pareamento inserido está incorreto ou expirado.   |
| `whatsapp_unavailable`  | O WhatsApp está temporariamente fora do ar.                   |

## Erros possíveis

| Status | Código de erro          | Descrição                                           |
| :----: | ----------------------- | --------------------------------------------------- |
| `402`  | `not_available_in_plan` | O plano atual não suporta números extras.           |
| `403`  | `not_authorized`        | A chave de acesso está inválida ou ausente.         |
| `404`  | `not_found`             | O alias informado não foi encontrado na conta.      |
| `500`  | `internal_error`        | Erro interno inesperado no servidor.                |
